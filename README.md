2. 自动提取每份发票的关键信息：
  非常好，这是你这套 “按行号提取发票信息” 的处理流程说明。下面是专业、清晰的文字版流程描述，可以直接写入你的技术文档或脚本注释中。

---
一、目标
  本流程用于从电子发票 PDF 文件中自动提取三个关键信息字段：
发票号码、开票日期、价税合计金额。
 核心方法基于关键字识别与相对行定位，以适应不同模板。

---
二、逻辑思路
  电子发票经过 PDF 文本提取后，版面结构在不同模板中可能略有差异，但仍保持以下规律：
  - 含“年”“月”“日”的行为开票日期；
  - 其上一行为发票号码；
  - 含“圆整”或“价税合计”字样的行为金额信息所在行。
  因此，本流程通过检测这些语义特征，自动定位目标行并提取数值。

---
三、处理流程
1️⃣ 读取与预处理
  使用 pdfplumber 读取 PDF 文件内容，合并多页文本。
 以换行符 \n 分割为文本行，去除空行与多余空格。
 结果为一个有序的行列表，每个元素代表发票中的一行。

---
2️⃣ 定位开票日期行
  在所有行中查找同时包含“年”“月”“日”的文本，例如：
  2025年10月04日
  该行为 开票日期。

---
3️⃣ 提取发票号码
  确定日期行的索引位置后，将其**上一行（index-1）**作为发票号码行。
   发票号码通常为 15–20 位数字，例如：
  25132000000173454978

---
4️⃣ 提取价税合计金额
  在所有行中搜索包含“圆整”或“价税合计”的文本行。
   从该行中提取最后出现的金额（带有“¥”或人民币符号），例如：
  叁佰柒拾伍圆整 ¥375.00
  最终输出金额为 ¥375.00。

---
5️⃣ 正则提取数值（增强鲁棒性）
  为适应不同发票样式，使用正则表达式从文本中提取干净内容：
  - r"\d{15,20}" → 发票号码
  - r"\d{4}年\d{1,2}月\d{1,2}日" → 日期
  - r"¥\s*\d+\.\d{2}" → 金额

---
6️⃣ 输出结构化结果
  将结果整合为结构化格式：
  {
  "发票号码": "25132000000173454978",
  "开票日期": "2025年10月04日",
  "价税合计": "375.00"
}
